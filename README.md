# Auto - Case Convolution Calculator

##Description
This mini project is a python-based visualization tool 
that helps engineering students to understand the convolution process
by displaying overlapping area between x(t) & h(t)

Instead of printing out y(t), system printing out
both x(t) and h(t-tau) graph in different overlap auto-casses 
to facilitate convolution understanding


##Motivation
Struggling understand signal processing, especially convolution.
In addition, other convolution calculator in website does not showing the process by each case (overlapping area),
therefore just made a simple graphing tool that shows convolution for all the cases.


##Before Use
Need to download two libraries
1. numpy
2. matplotlib


##How to run
Just write donw the input in terminal
(N is slicing preparing for integral, so N larger leads --> smoother graph)

providing cases : sin, cos, exp, pi, u
*Must Use Python Calculation writing for the input (ex: '3^t' ==> '3**')
*Do not copy and paste the equation, must write down in the terminal, else system cannot understand
